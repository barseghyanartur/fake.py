Creating images
===============
.. Internal references

.. _faker-file: https://pypi.org/project/faker-file/

Creating images for testing can be a challenging task. The goal of this
library is to help you out with basic tasks. You can easily generate very
basic graphic images (no custom shapes).

If you don't like how image files are generated by this library, you can
check the `faker-file`_ package, which can produce complex images.

Supported image formats
-----------------------
Currently, 8 image formats are supported:

- ``PNG``
- ``SVG``
- ``BMP``
- ``GIF``
- ``TIF``
- ``PPM``
- ``JPG``
- ``WEBP``

All other image formats (``SVG``, ``BMP``, ``GIF``, ``TIF``, ``PPM``,
``JPG`` and ``WEBP``) work in exactly the same way.

``JPG`` is a lossy format, so the colour of a produced ``JPG`` image may
differ from the given colour by 1 in each RGB channel. ``WEBP`` images are
lossless and always have exactly the given colour.

The following code will generate a 640x480 px ``JPG`` image filled with a
solid yellow colour.

.. container:: jsphinx-toggle-emphasis

    .. code-block:: python
        :name: test_jpg_file_640x480_yellow
        :emphasize-lines: 3

        from fake import FAKER

        FAKER.jpg_file(size=(640, 480), color=(182, 232, 90))

While the following code will generate a 640x480 px ``WEBP`` image filled
with a solid blue colour.

.. container:: jsphinx-toggle-emphasis

    .. code-block:: python
        :name: test_webp_file_640x480_blue
        :emphasize-lines: 3

        from fake import FAKER

        FAKER.webp_file(size=(640, 480), color=(18, 52, 185))

----
